# Codex Transcripts

توضع هنا نسخ غير معدلة من مراجعات Codex.

كل ملف Sign-off يجب أن يشير إلى transcript مطابق ويحتوي SHA256 الصحيح.

استخدم القالب:

`docs/templates/CODEX-TRANSCRIPT-TEMPLATE.md`

التسمية المقترحة:

```text
phase-1-week-1-codex-transcript.md
phase-1-final-codex-transcript.md
phase-3-final-project-codex-transcript.md
```

لا تعدل transcript بعد حساب SHA256. أي تعديل يتطلب مراجعة Codex جديدة وملف sign-off جديد.

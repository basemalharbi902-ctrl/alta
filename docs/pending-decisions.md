# قرارات العميل المعلقة

أي قرار أو مدخل غير متوفر من مالك المشروع أو جهة خارجية يوثق هنا قبل تسليم الأسبوع إلى Codex.

لا يسمح بإخفاء الافتراضات داخل الكود فقط. كل افتراض يجب أن يظهر هنا، وإذا دخل الكود مؤقتاً يعلّم بتعليق:

```php
// [CLIENT_PENDING] سبب الافتراض ورابط القرار في docs/pending-decisions.md
```

Blade:

```blade
{{-- [CLIENT_PENDING] سبب الافتراض ورابط القرار في docs/pending-decisions.md --}}
```

JavaScript/TypeScript:

```js
// [CLIENT_PENDING] سبب الافتراض ورابط القرار في docs/pending-decisions.md
```

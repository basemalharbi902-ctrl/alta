# الجزاءات عند تجاوز الحوكمة

## مخالفة أولى

أمثلة:

- بدء كود قبل اعتماد الخطة.
- فتح PR ناقص القوالب.
- عدم توثيق قرار عميل معلق.

الإجراء:

- رفض PR.
- إعادة العمل من آخر نقطة معتمدة.
- توثيق المخالفة في سجل PR.

## مخالفة ثانية

الإجراء:

- إيقاف العمل على الأسبوع.
- مراجعة إلزامية مع مالك المشروع.
- لا يستأنف العمل إلا بخطة تصحيح معتمدة من Codex.

## مخالفة ثالثة

الإجراء:

- إيقاف صلاحيات الدمج أو الكتابة إن وجدت.
- مراجعة عقدية/إدارية من مالك المشروع.
- لا يعود المبرمج للعمل إلا بقرار صريح من مالك المشروع واعتماد Codex لخطة استعادة.

## مخالفات تؤدي إلى رفض تلقائي بدرجة 0

- إخفاء افتراضات العميل داخل الكود.
- تعديل Sign-off أو transcript لتغيير نتيجة Codex.
- تجاوز Critical مفتوح.
- تسريب بيانات أو أسرار.
- محاولة الدمج خارج Branch Protection.

# حل الخلافات

## عند اعتراض المبرمج على ملاحظة Codex

1. يكتب المبرمج اعتراضاً فنياً موجزاً.
2. يرفق أدلة: كود، اختبار، قياس أداء، أو توثيق رسمي.
3. يرسل الاعتراض إلى مالك المشروع.
4. مالك المشروع وحده يعيد عرض الاعتراض على Codex.
5. قرار Codex بعد إعادة المراجعة هو القرار الفني الحاكم.

## ما لا يعتبر اعتراضاً مقبولاً

- "هذا أسرع".
- "هذا شائع".
- "سأصلحه لاحقاً".
- "المالك وافق".
- "لا يوجد وقت".

## عند استمرار الخلاف

يفتح مالك المشروع ملفاً في:

`docs/conflicts/`

ويجمد الجزء المختلف عليه حتى يصدر اعتماد Codex `100/100` أو يغير مالك المشروع نطاق العمل رسمياً.

# SLA مراجعات Codex

## الهدف

تنظيم انتظار مراجعات Codex بدون السماح للمبرمج بتجاوز البوابة.

## أزمنة الاستجابة المستهدفة

- مراجعة خطة أسبوعية: خلال يوم عمل واحد.
- مراجعة يومية: في نفس يوم العمل إن أمكن.
- مراجعة PR نهائية: خلال يومي عمل.
- Critical fix review: أولوية فورية قبل أي تطوير جديد.

## إذا تأخرت المراجعة

لا يحق للمبرمج البدء في عمل غير معتمد أو دمج PR.

المسموح فقط:

- تحسين التوثيق داخل نطاق الأسبوع.
- تجهيز اختبارات لم تنفذ بعد بدون تغيير منطق الإنتاج.
- تجهيز أسئلة أو قرارات معلقة لمالك المشروع.
- إصلاح ملاحظات سبق اعتمادها من Codex.

أي عمل جديد خارج الخطة المعتمدة يعتبر مرفوضاً.
